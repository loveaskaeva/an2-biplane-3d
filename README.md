# Бипланная коробка Ан-2 — 3D-модель

Интерактивная трёхмерная модель к НИР «Динамика и устойчивость связанных колебаний упругой механической системы
с предварительно напряжёнными связями под действием аэродинамических нагрузок (на примере бипланной коробки Ан-2)».

**Открыть:** https://loveaskaeva.github.io/an2-biplane-3d/

## Что показывает

- **Анализ.** Собственные формы полукоробки, форма флаттера, деформация и провисание лент-расчалок при перегрузке,
  частоты лент в зависимости от натяжения. Все данные взяты из конечно-элементного расчёта НИР.
- **Полёт.** Модель полёта с шестью степенями свободы: взлёт, посадка, вираж, горка, порыв ветра.
  Коробка колеблется по расчётным формам, приборная доска и вид из кабины.
  Четыре аварийные ситуации с лентами по РЛЭ Ан-2 (1983): порыв при ослабленных лентах, грубая посадка,
  обрыв несущей ленты, отказ виброгасителя.
- **Аэротруба.** Поток до 1000 км/ч, дивергенция и флаттер коробки.

## Файлы

- `index.html` — вся модель в одном файле. Библиотека three.js r128 загружается с CDN, поэтому нужен интернет.
- `an2_biplane_box.obj` — геометрия расчётной бипланной коробки для 3D-редакторов и PowerPoint.

Сайт собирается командой `python src/build_site.py` в проекте НИР.
